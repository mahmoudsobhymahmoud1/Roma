طريقة نشر الدعوة (مجانًا) - Netlify Drop
1) افتح https://app.netlify.com/drop
2) اسحب فولدر الموقع كله (أو ملف الـ zip) وسيبه يترفع.
3) هيطلعلك رابط زي https://اسم-عشوائي.netlify.app (تقدر تغيّر الاسم من Site settings > Change site name).
4) افتح index.html وغيّر السطر اللي فيه YOUR-SITE.netlify.app لرابط موقعك الحقيقي، وارفع تاني (عشان صورة المعاينة تظهر في واتساب).
5) جرّب الرابط من موبايل تاني قبل ما تبعته.

بديل: GitHub Pages - اعمل Repository جديد، ارفع الملفات، ثم Settings > Pages > Deploy from branch (main).
